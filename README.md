# Consultório Control

Sistema de gestão para consultórios, com foco em controle de clientes, agenda de consultas e finanças.

## Funcionalidades
- Login local com credenciais salvas no navegador
- Dashboard com resumo diário e financeiro
- Agenda de consultas
- Cadastro e gestão de clientes
- Controle financeiro e despesas
- Integração inicial com Firebase Firestore

## Estrutura do projeto
- `index.html` — ponto de entrada da aplicação
- `css/` — estilos do sistema
- `js/` — lógica principal da aplicação
- `assets/` — imagens e ícones
- `data/` — backups e dados exportados
- `rules/` — regras do Firebase
- `src/components/` — componentes reutilizáveis
- `src/modules/agenda/` — módulo de agenda
- `src/modules/clientes/` — módulo de clientes
- `src/modules/financeiro/` — módulo financeiro

## Como executar
1. Abra o arquivo `index.html` em um navegador.
2. Faça login com as credenciais locais configuradas no sistema.
3. Para conectar ao Firebase, use o painel de configuração e informe o JSON do projeto.

## Observações
Este projeto está em evolução e pode ser organizado ainda mais à medida que novas funcionalidades forem adicionadas.
